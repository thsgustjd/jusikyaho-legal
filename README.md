# JusikYaho 정책 문서 (웹 게시용)

이 폴더와 `docs/` 는 `npm run legal:export` 로 생성됩니다. 본문은 `mobile/constants/legalText.ts`, 운영자 정보는 `mobile/constants/legal.ts` 입니다.

## 지금 열려 있는 주소

- 개인정보 처리방침: https://thsgustjd.github.io/jusikyaho-legal/privacy.html
- 이용약관: https://thsgustjd.github.io/jusikyaho-legal/terms.html
- 투자 유의사항: https://thsgustjd.github.io/jusikyaho-legal/disclaimer.html

App Store / Play / Google OAuth 에는 **개인정보 처리방침** 주소를 넣습니다.

## GitHub Pages

저장소를 GitHub 에 연결한 뒤 Settings → Pages 에서 아래 중 하나를 고릅니다.

1. **Deploy from a branch** → `main` / `docs` 폴더
2. 또는 저장소에 포함된 `.github/workflows/pages.yml` 이 `legal/` 을 Pages 로 올립니다.
